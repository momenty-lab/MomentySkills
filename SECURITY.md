# Security policy

MomentySkills has not published a stable release. Security review should focus on executable scripts, installation guidance, links, and examples that could expose data or cause unintended changes.

GitHub private vulnerability reporting is enabled. Submit sensitive reports through [Report a vulnerability](https://github.com/momenty-lab/MomentySkills/security/advisories/new) and include the affected revision, impact, reproduction steps, and any safe mitigation. Do not place credentials, private prompts, proprietary code, or exploit details in a public issue.

Non-sensitive hardening suggestions may use a normal issue. No response or resolution time is promised while the project remains experimental.

For a suspected leaked secret, revoke or rotate it at its source first. Removing it from repository history is not sufficient.
