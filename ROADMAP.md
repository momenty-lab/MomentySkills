# Roadmap

The roadmap records intent, not a release commitment.

## Bootstrap

- Publish the original `adaptive-dev-routing` skill with bilingual onboarding.
- Establish safe installation, metadata, provenance, contribution, security, and conduct boundaries.
- Validate YAML, JSON, skill frontmatter, names, metadata, and local links in CI.

## Evidence loop

- Collect positive, neutral, mixed, and negative experience reports without rewarding a preferred direction.
- Refine the profile schema and evaluation protocol when reports expose ambiguity.
- Add reproducible examples that distinguish requested routing from observed runtime behavior.
- Define first-release criteria only after independent use reveals the main failure modes.

## Future skills

- Consider new skills when contributors demonstrate a repeatable development problem and a focused, portable intervention.
- Keep each skill independently understandable and avoid turning the collection into a private workspace mirror.
- Explore lightweight result summaries only after the underlying reports are comparable enough to aggregate honestly.
