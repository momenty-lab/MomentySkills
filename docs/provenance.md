# Provenance and disclosure

MomentySkills is intended to be an original public collection. Contributors should make it possible to understand where an instruction, example, claim, or asset came from and whether it can be redistributed.

## Initial repository

The initial repository text and `adaptive-dev-routing` materials were written for MomentySkills. The project was motivated by the founder's personal report that official Codex surfaces displayed 20 billion tokens of use. That statement is attributed experience, not an independently audited measurement or a performance result.

Public Codex skill discovery and installation behavior is documented by OpenAI in the [Codex skills documentation](https://developers.openai.com/codex/skills). Mention of Codex, OpenAI, model names, or GitHub identifies compatible tools and services; it does not imply affiliation or endorsement.

The initial public package excludes private or proprietary Momenty application source, private workspace rules, raw sessions, usage exports, credentials, signing data, personal information, logos, and third-party artwork. Development dependencies are referenced by version rather than vendored.

## Contribution rules

- Submit only content you wrote or have the right to redistribute under this repository's license.
- Identify external sources that materially shaped a technical claim or reusable artifact.
- Prefer links and short attribution over copying third-party manuals, skills, tests, templates, or artwork.
- Do not paste private prompts or rules merely to explain an idea; restate the general, original insight and remove identifying details.
- Mark examples as synthetic when they are not records of an actual run.
- Keep reported measurements connected to their source and preserve uncertainty.

If provenance is unclear, narrow or remove the material until its redistribution status can be established.
